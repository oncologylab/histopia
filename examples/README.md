# Histopia Examples

Configuration examples:

- `registration_config.toml`: reviewed serial-section registration.
- `semantic_atlas_config.toml`: UNI2-h feature extraction and global regions.
- `topology_config.toml`: physical-z semantic topology reconstruction.
- `stain_config.toml`: relative optical-density chromogen quantification.
- `cell_segmentation_config.toml`: native whole-slide cell boundaries.
- `semantic_probe_and_spatial_features.py`: portable linear probing and
  unit-aware spatial feature export from compact NPZ inputs.
